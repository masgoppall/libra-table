# Logo resmi driver

Taruh logo resmi di sini, satu file per driver, dengan nama sama seperti id driver (format SVG lebih baik):

postgres, mysql, sqlite, mariadb, cockroach, redshift, greenplum, vertica, libsql, cloudflare_d1, mssql,
oracle, clickhouse, duckdb, cassandra, snowflake, bigquery, redis, mongodb, dynamodb, elasticsearch

Contoh: `postgres.svg`, `mysql.svg`, `cloudflare_d1.svg`.

Sumber: halaman brand/press kit masing-masing vendor, atau simpleicons.org (logo merek dalam SVG satu warna).
Logo adalah merek dagang pemiliknya; ikuti pedoman penggunaan merek mereka.

Driver yang belum punya file di sini tetap memakai badge orisinal di `../badge/`.
